# Prompt 01: Project Foundation

Implement the foundational structure for the Spring Boot application.

Requirements:
- Create or update the Maven/Gradle project configuration so it can run as a Spring Boot app.
- Ensure Java 21 compatibility.
- Create the main application class.
- Create package folders for controller, service, dto, model, config, and util.
- Add application.properties with a basic app name and server port.
- Add a health endpoint at /health returning a simple success response.
- Keep the implementation minimal and clean.

Deliverables:
- working Spring Boot app entry point
- basic package structure
- health endpoint

Constraints:
- Do not over-engineer.
- Follow standard Spring Boot conventions.
- Keep the code compile-ready.
