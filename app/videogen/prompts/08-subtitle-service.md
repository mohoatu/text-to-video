# Prompt 08: Subtitle Service

Implement subtitle generation for the video assembly step.

Requirements:
- Create a service that builds subtitle lines from narration text.
- Generate subtitle timing information for each scene.
- Output subtitle content in a format suitable for FFmpeg overlay or SRT rendering.
- Keep the implementation simple and practical for MVP usage.

Deliverables:
- subtitle generation service
- subtitle file or subtitle payload

Constraints:
- Focus on basic correctness over advanced styling.
- Keep formatting consistent and easy to debug.
